## Compatibilidad con el Sistema

### Impresoras Soportadas

El sistema soporta impresion ESC/POS compatible con:
- Xprinter
- Epson TM-T series
- Star TSP series
- Bixolon

### Lectores Soportados

Cualquier lector USB que emule teclado (HID) funciona:
- Se conecta y listo (plug & play)
- No necesita drivers especiales
- Envia el codigo seguido de Enter

### Conexion de Cajon

El cajon se conecta via RJ11 a la impresora:
- La impresora envia pulso para abrir
- Configurable en el sistema (abrir al imprimir boleta)
